# CloudCC 数据建模指南

## 定位

数据建模用于把业务概念落到 CloudCC 的对象、字段、关系、选项集、记录类型和页面布局上。它是后续权限、自动化、报表、移动端和集成的基础。

## 事实依据

手册确认：

- 标准对象是 CRM 应用提供的默认业务对象。
- 自定义对象用于在 CloudCC 中存储组织数据。
- 字段分为标准字段和自定义字段。
- CloudCC 支持 20+ 字段类型，手册正文列出 23 种字段类型。
- 字段能力包括查找关系、主详关系、公式、自动编号、累计汇总、字段依赖、历史跟踪、主从录入。
- 页面布局支持详情页、行式布局、悬停页面布局、移动端页面布局，并可为不同简档分配不同布局。

## 建模对象

### 对象

对象是业务数据实体。标准对象适合 CRM 通用场景，自定义对象用于扩展企业专属业务。

### 字段

字段是对象的属性定义，决定记录能保存什么信息、如何录入、如何查询、如何参与自动化。

### 关系

手册确认的关系字段包括：

- 查找关系：将当前对象链接到另一对象。
- 主详信息关系：子记录与父记录之间的特殊关系，子记录权限和共享由主对象确定，主记录删除会影响子记录，并支持累计汇总。
- 查找多选：可选择多个关联记录。

### 选项集

选项列表和全局选项列表用于统一状态、分类、类型等枚举值。

### 衍生字段

公式字段、自动编号、累计汇总用于生成只读或系统计算值。

## 建模质量影响

字段和关系设计会影响：

- 页面录入体验
- 权限和字段级安全
- 验证规则和触发器复杂度
- 报表口径
- 数据导入导出
- OpenAPI 集成
- 移动端离线缓存
