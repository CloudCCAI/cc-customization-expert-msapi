# CloudCC 按钮与链接能力说明

## 1. 什么是按钮与链接

按钮和链接有助于将 CloudCC 数据与外部 URL、应用程序、公司内部网或其他后端办公系统集成在一起。

按钮可以显示在以下位置：
- **详细信息页**：记录详情页面上的操作按钮
- **相关列表**：对象关联子列表区域的操作按钮
- **列表视图**：搜索/列表布局中的批量操作按钮

---

## 2. 按钮分类

### 2.1 标准按钮（Standard Button）

系统内置的标准操作按钮，不可删除，可控制显示/隐藏。

| 标签       | 名称           | 显示类型         |
|------------|----------------|-----------------|
| 提交待审批  | Submit         | 详细信息页按钮   |
| 编辑        | Edit           | 详细信息页按钮   |
| 新建        | New            | 列表按钮         |
| 批量转移    | Batch Transfer | 列表按钮         |
| 删除        | Delete         | 详细信息页按钮   |
| 批量新增    | Batch Added    | 列表按钮         |
| 复制        | Clone          | 详细信息页按钮   |
| 共享        | Share          | 详细信息页按钮   |
| 批量删除    | Batch Delete   | 列表按钮         |
| 批量编辑    | Batch Editor   | 列表按钮         |
| 合并        | Merge          | 列表按钮         |

### 2.2 自定义按钮（Custom Button）

开发者自定义的按钮或链接，支持配置跳转 URL、执行脚本、调用自定义类等行为。

---

## 3. 按钮类型（btnType）

| 值          | 说明           |
|-------------|----------------|
| `detailBtn` | 详细信息页按钮  |
| `listBtn`   | 列表按钮        |

## 4. 按钮行为（event）

| 值            | 说明                   |
|---------------|------------------------|
| `lightning` | PC 端脚本模板按钮；界面显示为 `template` |
| `lightning-script` | PC 与移动端脚本按钮 |
| `lightning-url` | PC 与移动端页面或链接按钮 |
| `URL` | 普通 URL 跳转按钮；界面显示为 `url` |

完整创建字段、JSON 示例和兼容别名以 `cloudcc doc platform/button devguide` 为准；不要再使用旧的 `JavaScript` event 值。

---

## 5. 如何将按钮添加到页面

- **详细信息页**：先创建按钮，再在页面布局 JSON 的 `buttons[]` 中使用真实回读的 `buttonId` 挂载
- **相关列表**：先创建按钮，再在页面布局 `relatedLists[].buttons[]` 中使用真实回读的 `buttonId` 挂载
- **列表视图**：在"搜索布局"中编辑列表视图布局

页面布局中的按钮只是引用关系，不会隐式创建按钮定义。完整页面布局示例见：

```bash
cloudcc doc platform/pagelayout devguide
```
