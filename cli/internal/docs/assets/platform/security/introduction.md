# CloudCC 权限与安全模型

## 定位

CloudCC 的权限体系用于回答五个问题：

1. 用户能否登录系统？
2. 用户能看到哪些应用和菜单？
3. 用户能对哪些对象执行查看、新建、编辑、删除等操作？
4. 用户能看到哪些记录？
5. 用户能看到或编辑哪些字段？

## 核心能力

### 角色 Role

手册说明角色树用于控制数据及访问权限。通常上级可以查看下级拥有或可查看的数据，同级之间不可相互查看。角色树还可与共享设置配合，将某类数据共享给某个角色或角色及下属。

### 简档 Profile

简档控制用户的基础权限集合。手册中简档覆盖：

- 应用程序可见和默认应用
- 菜单显示方式
- 对象操作权限：只读、新建、编辑、删除、查看全部、修改全部
- 字段控制：可见、只读
- 标准字段级安全性和自定义字段级安全性
- 手机端设置
- 集成应用管理
- 普通用户权限
- 密码策略、登录时间、登录 IP 等

### 权限集 Permission Set

技能文档说明权限集用于管理权限集列表、查看已分配用户、添加和删除分配用户。手册中也把权限集描述为简档的附加组件，可向用户添加对象、字段级安全性、页面布局、记录类型、应用程序、菜单等权限。

### 共享设置与共享规则

手册说明共享设置显示组织范围默认共享设置；角色层次结构可自动授予记录访问权限；共享规则用于对组织范围默认设置做例外扩展，支持基于记录所有人或记录字段条件创建共享。

### 公用小组与队列

手册提到公用小组和队列。队列用于让用户组处理共享工作负载，记录保留在队列中直到成员接受处理或转移。

### 身份提供商与单点登录

身份提供商用于 SAML 身份提供商配置，单点登录用于服务提供商配置。手册还提到第三方验证提供商可通过 OpenID Connect 或 OAuth 2.0。

### 审计与登录安全

手册包含密码策略、登录时间、登录 IP、系统重点操作审计日志、计划作业监控等安全能力。

## 权限决策树

| 问题 | 优先能力 |
|---|---|
| 能不能登录 | 用户、密码策略、登录时间、登录 IP、SSO |
| 能不能看到应用 | 简档的应用程序设置 |
| 能不能看到菜单 | 简档的菜单设置 |
| 能不能操作对象 | 简档或权限集的对象权限 |
| 能不能看到字段 | 字段级安全性 |
| 能不能看到某条记录 | 角色层级、共享设置、共享规则、队列、公用小组 |
| 临时增加权限 | 权限集 |
