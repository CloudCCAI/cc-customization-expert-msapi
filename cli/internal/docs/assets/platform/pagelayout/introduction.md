# 页面布局（Page Layout）介绍

页面布局是 CloudCC 中用于定义对象详情页展示方式的重要配置。

## 什么是页面布局？

页面布局决定了：
- 字段在详情页如何排列和分组
- 哪些字段显示、哪些隐藏
- 操作按钮的位置和顺序
- 相关列表的展示方式
- 动态布局规则（根据条件显示/隐藏字段）

页面布局也是字段语义落位的设计载体。新增字段不应只按创建顺序追加到页面底部，而应结合字段标签、API 名、字段类型、业务说明、当前对象的全局字段字典和已有分组，把字段放到用户最可能查找和编辑的位置。

## 适用对象

页面布局可以应用于：
- **标准对象**：如 Account（客户）、Contact（联系人）等系统内置对象
- **自定义对象**：用户根据业务需求创建的对象

## 前置条件

操作页面布局前，必须先**选中对象**（自定义对象或标准对象）。

## 核心能力

| 能力 | 说明 |
|------|------|
| 查询布局列表 | 查看对象下的所有页面布局 |
| 创建布局 | 基于现有布局复制创建新布局 |
| 复制动态规则 | 可选择是否复制源布局的动态布局规则 |
| 字段语义落位 | 根据字段含义选择分组、行列和 PC/mobile 布局位置 |

## 使用场景

1. **多终端适配**：为 PC 端和移动端创建不同的布局
2. **多角色视图**：为不同角色创建差异化的详情页展示
3. **业务场景适配**：针对特定业务流程定制字段展示
