# CloudCC 移动端方案设计指南

## 设计步骤

### 1. 判断是否是移动优先场景

典型移动场景：

- 外勤拜访
- 签到定位
- 名片扫描
- 移动审批
- 离线录入
- 移动销售看板
- 快速任务处理

### 2. 先确认对象和字段

移动端录入依赖对象字段模型。字段太多、关系太复杂会直接影响移动体验。

### 3. 设计移动端布局

手册确认平台支持移动端页面布局。应单独评估移动端字段顺序、必填字段和相关列表。

### 4. 设计权限和菜单

移动端可用能力受简档、菜单、应用和对象权限影响。

### 5. 设计离线缓存

如需要离线使用，应确认：

- 哪些菜单进入离线缓存
- 哪些对象允许离线新建/编辑/删除
- 离线后的同步冲突如何处理

手册未详细说明冲突策略，涉及该点需要实际租户验证。

### 6. 设计扫一扫和签到

如启用扫一扫/名片扫描/签到，需要确认：

- 是否保存名片图片到附件
- 是否执行验证规则
- 是否允许从相册上传
- 是否添加日期、时间、地址水印

## 行业通用建议

- 移动端字段要少于 PC 端详情页。
- 移动端优先展示任务、审批、签到、客户、联系人等高频入口。
- 离线缓存只选择真正需要离线的对象，避免同步压力过大。
- 名片扫描保存时建议开启验证规则和查重策略。
- 签到照片、水印和定位涉及管理制度，应让业务方确认。

## Agent 输出清单

- 移动场景
- 涉及对象
- 移动端布局
- 权限和简档
- 是否离线
- 是否扫码/签到
- 验证规则和查重
- 待确认的移动端限制
