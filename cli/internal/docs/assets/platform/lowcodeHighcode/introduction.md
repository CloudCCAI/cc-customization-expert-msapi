# CloudCC 低代码 + 高代码协同模型

## 定位

CloudCC PaaS 同时支持低代码配置和高代码开发。正确的实施方式不是二选一，而是先用低代码沉淀稳定模型，再用高代码解决复杂逻辑、复杂体验和复杂集成。

## 低代码能力

已确认低代码能力包括：

- 对象、字段、关系、记录类型、全局选项列表
- 应用、菜单、视图
- 页面布局、自定义页面
- 验证规则、查重过滤器
- 工作流、批准、动作
- 角色、简档、权限集、共享规则
- 数据导入导出
- 移动端配置
- 多语言工作台

## 高代码能力

已确认高代码能力包括：

- Java 类
- Java 触发器
- 定时类
- 客户端脚本
- 自定义 HTML
- Vue pagecomponent
- 静态资源
- OpenAPI
- sidecar 中间程序目录

## 协同原则

- 数据模型用低代码优先。
- 权限治理用平台权限优先。
- 简单校验用验证规则优先。
- 常规通知和字段更新用工作流/动作优先。
- 页面标准展示用页面布局优先。
- 局部前端行为用客户端脚本。
- 复杂交互用自定义页面和 pagecomponent。
- 复杂服务端业务用类和触发器。
- 周期性任务用定时类和定时作业。
- 平台外运行需求用 sidecar。

## 适用场景

低代码适合：

- 快速建业务台账
- 标准 CRM 流程
- 权限和字段控制
- 简单流程自动化
- 移动端基础适配

高代码适合：

- 跨对象复杂逻辑
- 外部系统集成
- 复杂 UI 和可视化
- AI/地图/图表等前端 SDK
- 大批量后台处理
- 可复用服务端能力
