# CloudCC PaaS 平台能力总览

## 定位

CloudCC PaaS 是以 CRM 业务对象为核心的企业应用平台。它同时提供低代码配置能力和高代码扩展能力，用于构建、运行、管理和优化企业业务应用。

本说明依据：

- `CloudCC平台操作手册.pdf`
- 当前技能内置的对象、字段、权限、页面、自动化、开发者空间、OpenAPI 等模块文档
- `cc-setup-service` 后端源码中的 setup controller/service 包结构

## 三层能力模型

CloudCC PaaS 可以按三层理解：

```text
数据模型层：对象、字段、关系、记录类型、选项集、数据质量
业务逻辑层：验证规则、查重、工作流、审批、动作、触发器、类、定时任务
体验交付层：应用、菜单、视图、页面布局、自定义页面、组件、移动端、门户和沟通渠道
```

## 平台核心能力

### 1. 元数据驱动建模

平台通过标准对象和自定义对象承载业务数据。对象之上可以配置字段、关系、页面布局、菜单、权限、自动化逻辑和报表基础。

手册明确说明：

- 自定义对象用于在 CloudCC 中存储组织数据。
- 字段用于描述对象属性。
- 平台支持 20+ 字段类型，手册正文列出 23 种字段类型。
- 对象可配置快速创建、定位服务、允许报表、对象权限等。

### 2. 低代码应用搭建

低代码能力包括：

- 应用程序：把菜单组合为业务应用。
- 菜单：提供对象、页面、脚本等入口。
- 视图：组织列表页筛选和工作入口。
- 页面布局：配置详情页、行式布局、悬停布局、移动端布局。
- 自定义页面：通过拖拽组件搭建业务页面。
- 模板、相关列表样式、详情页报表图集等页面增强能力。

### 3. 企业权限与安全治理

平台通过角色、简档、权限集、共享设置、共享规则、字段级安全、登录策略、身份提供商、单点登录和审计日志组成权限治理体系。

手册明确提到：

- 角色树用于控制数据及访问权限。
- 简档控制应用、菜单、对象操作权限、字段可见和只读、登录时间、登录 IP、密码策略等。
- 共享设置与共享规则用于扩展记录可见范围。
- 身份提供商和单点登录用于外部身份集成。
- 系统重点操作审计日志用于系统追溯。

### 4. 自动化与流程

平台自动化能力包括：

- 验证规则：保存前校验数据。
- 查重过滤器：新建或编辑时识别重复数据。
- 工作流：基于对象和条件执行任务、邮件、短信、字段更新等动作。
- 批准过程：支持多级审批。
- 动作：手册提到任务、电子邮件通知、字段更新、触发器、Webhook。
- 定时类和定时作业：按时间规则执行后台任务。

### 5. 高代码开发者空间

开发者空间支持：

- 类：服务端 Java 代码，可用于自定义页面和触发器。
- 触发器：记录插入、更新、删除、审批等事件前后执行 Java 逻辑。
- 定时类：定时程序的服务端代码。
- 定时作业：配置定时类的执行计划。
- 自定义页面和自定义组件：扩展 UI。
- 软件包：迁移类、自定义页面、自定义组件、应用程序等。
- 静态资源：托管 JS、CSS、图片、压缩包等。
- 客户端脚本：运行在 Lightning 前端客户端的 JavaScript 片段。

### 6. 集成、移动和数据管理

手册还覆盖：

- 电话/CTI、Email to Case、Email to Lead、在线聊天、在线个案、客户满意度、消息通知。
- Mailchimp、天眼查、企业微信、钉钉、短信等集成。
- 数据导入、导出、批量转移、批量删除、批量转移批准请求。
- 多语言设置、翻译、导入导出。
- 移动端主页、离线缓存、扫一扫、签到、水印、快捷入口、一级页面。

## 与低代码 + 高代码平台的关系

CloudCC 的低代码能力用于快速建模、配置页面、控制权限和编排流程；高代码能力用于处理复杂逻辑、复杂 UI、系统集成、批处理和性能敏感的业务扩展。

推荐原则：

- 先使用低代码配置完成对象、字段、权限、布局和基础流程。
- 当规则不可配置、交互复杂、需要外部系统集成或需要批处理时，再使用高代码扩展。
- 不要一开始就把所有需求写成触发器或自定义组件。
