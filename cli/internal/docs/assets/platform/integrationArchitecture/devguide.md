# CloudCC 集成方案选择指南

## 先确认集成目标

| 目标 | 优先方案 |
|---|---|
| 外部系统读写 CloudCC 数据 | OpenAPI |
| CloudCC 内执行复杂业务逻辑 | 类 |
| 记录变化时触发内部逻辑 | 触发器 |
| 周期性同步或补偿 | 定时类 + 定时作业 |
| 前端页面接入外部 SDK | pagecomponent + staticResource |
| 企业统一登录 | identityProvider / singleSignOn |
| 平台外中间层处理 | sidecar |

## OpenAPI 适用场景

适合：

- 外部系统同步对象数据
- 独立前端读取 CloudCC 数据
- 数据查询、分页查询、创建、更新、删除、upsert

注意：

- 当前技能 CLI 可读取项目配置中的 `apiSvc` 和 `accessToken`。
- 具体接口能力以 `cloudcc doc platform/openapi devguide` 为准。

## 类适用场景

适合：

- 封装可复用服务端业务逻辑
- 为自定义页面和自定义组件提供后端能力
- 触发器中调用公共逻辑

## 定时同步适用场景

适合：

- 主数据定时拉取或推送
- 外部系统失败补偿
- 大批量历史数据修正
- 报表底表刷新

## Sidecar 适用场景

以下为通用架构建议：

- 需要运行非 Java/非平台运行时逻辑
- 需要长连接、队列消费者、文件处理、AI 服务代理
- 需要隔离外部系统凭据
- 需要独立部署、扩缩容或观测

当前技能只规定 `sidecar/` 目录，不规定具体语言或框架。

## 集成设计必须确认

- 数据方向：CloudCC 到外部，外部到 CloudCC，还是双向
- 鉴权方式：token、SSO、OAuth、SAML、专用账号
- 数据主权：哪个系统是主数据源
- 幂等规则：重复请求如何处理
- 失败重试：谁重试，重试多久
- 日志审计：在哪里查失败原因
- 权限边界：集成账号是否最小权限

## 不确定事项

手册只概述部分预置集成，未给出全部接口参数。涉及 Mailchimp、天眼查、企业微信、钉钉、短信、CTI 等具体接入参数时，需要查看对应租户后台页面或后端源码进一步确认。
