# CloudCC 自定义设置介绍

自定义设置是一个聚合元数据资源，由主对象、字段、多语言标签以及页面布局共同组成。CLI 通过 MetadataService 生成可审查、可应用、可回滚的变更计划；新增或修改字段时，会同时维护字段的默认语言标签和布局可见性，避免字段已写入数据库但详情页无法显示。

自定义设置支持列表型和层次型配置。对已有自定义设置执行 `update` 时采用局部更新语义：省略主对象属性不会重写对象名、物理表名或前缀；字段按 ID 或同一自定义设置内的 API 名识别，可在同一次更新中新增和修改。

完整操作说明：`cloudcc doc platform/customSetting devguide`。
