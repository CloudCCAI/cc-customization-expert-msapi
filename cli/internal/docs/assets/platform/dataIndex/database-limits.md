# dataIndex 数据库限制

## 通用平台限制

- 默认每表最多 32 个索引，配置项为 `MDS_BUSINESS_DATA_INDEX_MAX_PER_TABLE`。
- 单个业务索引最多四个字段。
- 索引名称按数据库标识符限制生成：Oracle 30、Kingbase/PostgreSQL 63、其他数据库 64 个字符。
- 有效数量上限取平台配置和数据库硬限制中的较小值；达到上限时创建在 DDL 前失败，并提示执行 `analyze dataIndex`。

## 数据库差异

- MySQL InnoDB：最多 64 个二级索引；索引键长度还受页大小、字符集和行格式影响。
- Oracle：每表索引数量没有固定的小上限，但键长度受数据库块大小影响，仍执行平台数量限制。
- KingbaseES/PostgreSQL 系：每表索引数量通常受关系对象资源约束，单索引列数通常最多 32；Skill 仍执行更严格的四字段和平台数量限制。
- H2 仅用于自动化验证，不代表生产数据库锁和空间行为。

当数据库实际配置比文档更严格时，以数据库返回为准；CLI 会把常见厂商错误转换为稳定、可操作的失败原因。
