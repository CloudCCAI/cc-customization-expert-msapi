# 售后服务工单 Playbook

## 定位

本 playbook 用于 CloudCC 售后服务、现场服务、资产服务和工单闭环设计。它适合制造业设备、工程机械、工业产品等需要服务请求、派工、现场执行、索赔、结算和回访的场景。

说明：

- 本文为真实项目蓝图的抽象方法论，不包含客户专有信息。
- 工单类型、状态、费用规则、派工规则需要按项目确认。

## 服务闭环

```text
服务发起
  -> 工单生成
  -> 调度派工
  -> 现场执行
  -> 完工资料
  -> 技术报告
  -> 索赔
  -> 结算
  -> 回访评价
  -> 数据分析
```

## 服务发起渠道

- 400 呼叫中心。
- 小程序或客户门户。
- 人工录入。
- 车联网故障或工况规则。
- 工厂主动计划，如巡检、技改、拜访。

## 工单生成方式

- 手动创建。
- 按审批或销售交付结果自动创建。
- 按定时策略周期创建。
- 按车联网数据自动创建。
- 按批量导入创建。

## 常见工单类型

- 交机工单。
- 点检/保养工单。
- 巡检工单。
- 技改工单。
- 召请/维修工单。
- GPS 故障工单。
- 主动拜访工单。
- 预验收或防锈运转类工单。

## 核心对象

- 服务请求。
- 服务工单。
- 资产。
- 服务商。
- 服务网点。
- 服务工程师。
- 服务工作记录。
- 工单照片。
- 配件更换单。
- 维修作业单。
- 技术支持申请。
- 索赔单。
- 结算单。
- 满意度评价。
