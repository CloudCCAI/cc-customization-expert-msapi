# 小程序与客户门户 Playbook

## 定位

本 playbook 用于 CloudCC 项目中的微信小程序、客户门户、服务门户和商城入口设计。它关注身份、注册认证、设备绑定、服务申请、进度查询、通知、评价和商品浏览等能力。

## 常见入口

- 服务小程序。
- 客户自助服务门户。
- 电子商城小程序。
- 在线客服入口。
- 设备绑定和设备详情入口。

## 核心能力

- 微信授权或手机号登录。
- 用户注册和认证。
- 企业或个人身份绑定。
- 设备绑定。
- 服务召请。
- 保养预约。
- 服务订单和工单进度查询。
- 微信通知。
- 服务评价。
- 产品和备件浏览。
- 在线客服和电话客服。

## 对象建议

- 微信用户。
- 用户认证信息。
- 设备绑定。
- 服务请求。
- 服务工单。
- 服务评价。
- 商品或产品展示。
- 订单。
- 轮播图或内容配置。
