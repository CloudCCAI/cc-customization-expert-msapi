# 制造业营销服一体化 Playbook

## 定位

本 playbook 用于制造业、装备制造、工程机械等场景的 CloudCC CRM/PaaS 方案设计。它把渠道、市场、销售、合同、订单、回款、资产、售后服务和外部系统集成组织成一张能力地图。

说明：

- 本文来自真实蓝图文档的抽象，不包含客户名称、接口地址或专有规则。
- 具体行业术语、岗位、阈值、审批链路需要按项目确认。

## 端到端流程

```text
MPR：伙伴关系管理
MTL：市场到线索
LTC：线索到回款
ITR：问题到解决 / 售后服务闭环
MCR：用户经营和客户关系深化
```

## 能力地图

### MPR 伙伴关系管理

- 代理商/经销商招募。
- 准入、升降级、评级。
- 合作协议、电子签章、保证金。
- 样机申请、发运、库存。
- 服务商、服务网点、服务工程师。

### MTL 市场到线索

- 市场活动。
- 活动预算。
- 表单推广。
- 员工邀约。
- 线索采集、评分、培育。
- 线索转商机。

### LTC 线索到回款

- 商机/项目。
- 报价、选配、融资方案。
- 合同和合同变更。
- 订单、交货、调拨。
- 开票、收款、回款认领。
- 交付、物流、库存和生产状态可视化。

### ITR 售后服务

- 服务请求。
- 服务工单。
- 自动派工和人工派工。
- APP 现场执行。
- 技术支持。
- 索赔、结算、回访评价。

### 用户和资产中心

- 客户、联系人。
- 产品和设备型号。
- 资产档案。
- 设备绑定。
- 保修、跨区、服务归属。

### 集成生态

- ERP。
- BPM/OA。
- MDM。
- TMS。
- 呼叫中心。
- 信用平台。
- 资金系统。
- 车联网。
- QMS/WMS。
- 小程序/客户门户。
